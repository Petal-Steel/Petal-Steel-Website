# Petal Steel Art

Static portfolio foundation for Petal Steel Art, built with Astro for GitHub Pages compatibility.

## Local development

Requires a current Node.js LTS release (20 or newer) and npm.

```sh
npm install
npm run dev
```

## Checks

```sh
npm run check
npm run build
```

The static production output is written to `dist/`. See [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md), [`docs/CONTENT-CONVENTIONS.md`](docs/CONTENT-CONVENTIONS.md), and [`docs/VISUAL-PRINCIPLES.md`](docs/VISUAL-PRINCIPLES.md).
