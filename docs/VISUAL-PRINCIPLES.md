# Visual foundation

The interface is a contemporary gallery built from steel: dark charcoal and graphite surfaces, muted steel-toned rules, soft off-white type, and generous space. It must not imitate a metal surface.

Avoid brushed-metal treatments, diamond plate, faux rust, decorative sparks, industrial clip art, and gratuitous texture. Motion remains minimal and functional. Artwork photography supplies the literal material, texture, and context.

The baseline CSS tokens live in `src/styles/global.css`. The shared shell and homepage use a restrained editorial treatment that keeps sculpture photography primary. Layout refinements should preserve that established composition and visual system.
